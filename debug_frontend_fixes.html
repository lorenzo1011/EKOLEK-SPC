Frontend Issues Fixed

✅ Fix 1: "Welcome undefined" Issue

Problem: QR login showed "Welcome undefined! Redirecting..." instead of user name.

Root Cause: login.js expected `data.user_name` but backend only returned `data.user_id`

Solution Applied:

  • Updated auth_views.py to include `user_name: user.first_name or user.username` in QR login response
  • Updated otp_views.py to include `user_name` in OTP verification response
  • Modified login.js to handle undefined user_name gracefully with fallback to 'User'

🔧 Fix 2: Extra JavaScript Text Display

Problem: JavaScript code was visible at bottom of OTP verification page.

Root Cause: CSS not properly hiding script content that may have become visible

Solution Applied:

  • Added stronger CSS rules to hide script content with `!important` declarations
  • Added multiple CSS safeguards including visibility, position, and overflow controls
  • Added body overflow controls to prevent content from leaking outside bounds
